КОСАРЬ.IO — как запустить игру
===============================

Это ВЕБ-ИГРА (сайт), а не программа .exe. Файл index.html не запускается
двойным кликом — браузер блокирует загрузку игры с диска. Нужен любой
локальный сервер. Три способа, от простого к продвинутому:

1) ИГРАТЬ СРАЗУ (без установки)
   Откройте игру в окне предпросмотра, из которого скачивали архив —
   там она уже работает по ссылке.

2) ГОТОВАЯ СБОРКА (папка dist)
   В архиве найдите папку dist — в ней index.html и папка assets.
   Они работают ТОЛЬКО вместе, не переносите index.html отдельно.
   - Откройте терминал (командную строку) внутри папки dist
   - Выполните:  npx serve   (нужен Node.js)
     или:        python -m http.server
   - Перейдите в браузере по адресу, который покажет команда
     (обычно http://localhost:3000)

3) ИЗ ИСХОДНИКОВ
   - Установите Node.js с сайта nodejs.org
   - В папке проекта выполните:  npm install
   - Затем:                      npm run dev
   - Откройте http://localhost:3000
   - Для финальной сборки:       npm run build  (результат — папка dist)

УПРАВЛЕНИЕ
   ПК:      мышь или WASD — движение, Пробел/Shift — ускорение,
            Esc — пауза, M — звук
   Телефон: джойстик слева, кнопка «Буст» справа

Прогресс, роса, скины и рекорды сохраняются в браузере автоматически.
