Косарь.io

Это веб-игра, и её нельзя запустить двойным кликом по файлу — браузер запрещает загружать модули игры прямо с диска. Игра цела и невредима, её просто нужно открыть через сервер. Выбирайте самый удобный способ:

  1. Проще всего: играйте прямо в окне предпросмотра, из которого скачивали ZIP — там игра уже запущена по ссылке.
  2. Готовая сборка: в архиве найдите папку dist — внутри index.html и папка assets (они работают только вместе). Откройте терминал в папке dist и выполните npx serve или python -m http.server, затем перейдите по показанной ссылке вида http://localhost:3000.
  3. Из исходников: установите Node.js с nodejs.org, затем в папке проекта выполните npm install и npm run dev — игра откроется на http://localhost:3000.
Если в архиве нет папки dist, соберите её командой npm run build после npm install. Прогресс, скины и рекорды сохраняются в браузере автоматически.
